# Media Downloader v2.0.0

Une application de telechargement de medias universelle pour Windows.

## Fonctionnalites

- **+1000 sites supportes** : YouTube, TikTok, Instagram, Twitter/X, Facebook, Twitch, et bien plus
- **Interface graphique moderne** avec mode sombre/clair
- **Detection automatique** de la plateforme
- **Formats audio** : MP3, AAC, WAV, FLAC, OGG, M4A, OPUS, WMA
- **Formats video** : MP4, MKV, WEBM, AVI, MOV, FLV
- **Qualites video** : 144p a 8K (selon disponibilite)
- **Barre de progression** en temps reel
- **Historique des telechargements**
- **Choix du dossier de destination**
- **Renommage des fichiers**

## Installation

1. Telechargez `MediaDownloader.exe` ci-dessous
2. Installez FFmpeg : `winget install FFmpeg`
3. Lancez l'application

## Configuration requise

- Windows 10/11 (64-bit)
- FFmpeg installe et dans le PATH
- Connexion Internet
